# FoodieHub Frontend ??

Modern React (Vite) + Tailwind CSS Single-Page Application for the FoodieHub Online Food Ordering System.

## Features
- Customer food discovery, restaurant menus, and category filtering
- Cart state & persistent order checkout with discount coupons
- Real-time order progress tracking and review ratings
- Restaurant Owner and Administrator consoles with role-based routing
- Responsive modern UI inspired by Swiggy / Zomato

## Getting Started
```bash
npm install
npm run dev
```

## Production Deployment (Vercel)
- **Framework Preset**: Vite
- **Root Directory**: `./`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Environment Variable**: `VITE_API_URL=https://<your-backend-domain>/api`
